# requirements_matrix.md — Requirement Traceability Matrix (RTM)

Источник требований: `db_dec.docx` (полностью прочитан; разделы 2–5 + приложение 2). Исключения и условия стандарта
сохранены в столбце «Критерий». Ссылки /4/–/12/ в документе **не приложены**: зависимые критерии помечены `[/N/ отсутствует]`.

Статусы: **С** — соответствует; **СУ** — соответствует при условиях; **НС** — не соответствует; **НП** — не поддерживается;
**НПд** — не подтверждено; **НА** — неприменимо; **ЭП** — требует эксплуатационной проверки.
Уверенность: H/M/L. Доказательства — см. findings.md (F-xx), test_plan.md (T-xx), evidence/*.
